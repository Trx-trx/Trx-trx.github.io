# Trx-trx.github.io

RunXi Tang personal page.

Static personal homepage, deployed directly with GitHub Pages.

## Publish

1. Push this directory to the repository's `main` branch.
2. In GitHub, open **Settings -> Pages** and choose `Deploy from a branch`.
3. Select `main` / `/ (root)`, then wait for deployment.

The email, social links, and project copy are in `index.html` and can be replaced as needed.

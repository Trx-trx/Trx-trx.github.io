# Trx-trx.github.io

RunXi Tang personal page.

Static personal homepage. GitHub Pages publishes the `docs` directory from the `main` branch.

## Publish

1. Push this directory to the repository's `main` branch.
2. In GitHub, open **Settings -> Pages** and choose `Deploy from a branch`.
3. Select `main` / `/docs`, then wait for deployment.

The email, social links, and project copy are in `docs/index.html` and can be replaced as needed.
